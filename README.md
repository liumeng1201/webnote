# WebNote 云便签

极简的在线数据暂存与传送工具：不用注册、不用登录，打开 `/<名字>` 就是一个便签空间，在任何设备上同步文本、暂存文件。

单二进制部署，零外部依赖（Go 标准库实现，数据为本地 JSON 文件），轻量、启动快、易备份易迁移。

## 功能

- **便签空间**：访问 `/<名字>` 即创建/打开空间（名字支持字母、数字、中文和 `- _ .`），同名同空间，跨设备同步
- **多标签**：一个空间内可建多个标签，内容自动保存（带版本冲突检测，多设备同时编辑不互相覆盖）
- **标签标题**：选填；留空时显示内容第一行；双击标签可改名
- **拖拽排序**：按住标签拖动即可调整顺序（支持触屏）
- **访问密码**：空间可设置访问密码；直达链接格式 `/<名字>@<密码>`，打开即解锁
- **只读模式**：开启后所有人只能查看，不能修改
- **文件暂存**：独立于标签的文件区，分片上传（默认 16 MB/片，绕过代理的单请求大小限制，带进度显示）；单个文件默认上限 300 MB；上传时选有效期 1–3 天（默认 1 天），到期自动删除，也可手动删除；下载支持断点续传（Range）
- **自动备份**：按间隔自动快照**便签数据**（不含暂存文件本体，体积小），保留最近 N 份；整个数据目录可直接拷贝迁移
- **管理后台** `/admin`：查看每个空间的标签数、文件数、每个标签占用大小；可强制删除空间/标签/文件；可一键下载备份包。仅需管理员密码（启动时指定，只存哈希，与数据无关，换密码重启不影响已有数据），登录带失败限速

## 构建与运行

需要 Go 1.23+：

```bash
go build -o webnote .
./webnote -port 8080 -data-dir ./data -config ./config.json -admin-password '你的管理员密码'
```

首次启动后打开 `http://localhost:8080/` 即可使用。

## 启动参数与配置

参数优先级：**命令行参数 > 配置文件 > 内置默认值**。启动时会把最终生效的参数写回配置文件（默认 `config.json`，权限 0600，管理员密码只存哈希）。之后可直接用 `-config <路径>` 按文件启动；再带命令行参数则覆盖并回写。

| 参数 | 配置键 | 默认 | 说明 |
|---|---|---|---|
| `-port` | `port` | 8080 | 监听端口 |
| `-data-dir` | `data_dir` | `./data` | 数据目录 |
| `-config` | — | `config.json` | 配置文件路径 |
| `-admin-password` | `admin_hash` | （空=禁用后台） | 设置管理员密码（仅保存哈希） |
| `-backup-interval` | `backup_interval_hours` | 6 | 备份间隔（小时） |
| `-backup-keep` | `backup_keep` | 7 | 备份保留份数 |
| `-file-cap-gb` | `file_cap_gb` | 20 | 文件暂存总容量上限（GB） |
| `-file-max-mb` | `file_max_mb` | 300 | 单个文件大小上限（MB） |
| `-chunk-mb` | `chunk_mb` | 16 | 上传分片大小（MB） |

无 systemd 的环境可用普通脚本托管，例如：

```bash
nohup ./webnote -config ./config.json >> webnote.log 2>&1 &
```

## 数据布局与备份恢复

```
data/
  spaces/    每个空间一个 JSON（便签全部数据，文件名是空间名的 SHA-256）
  files/     暂存文件本体
  uploads/   未完成上传的临时分片（重启后自动清理）
  backups/   定时快照（仅 spaces/ 的副本）
```

- **备份**：`backups/<时间戳>/` 下是空间 JSON 的副本；管理后台也可随时下载 `.tar.gz` 备份包。备份不包含暂存文件本体。
- **恢复/迁移**：把 `spaces/`（或某个备份快照里的文件）放回新实例的 `data/spaces/` 后启动即可；服务启动时会自动清理“有记录但文件本体不存在”的文件条目。
- **过期清理**：服务每 10 分钟扫描一次，删除到期文件与滞留超过 2 小时的未完成上传。

## 安全说明

- 空间名本身即访问凭证：未设密码的空间，任何知道名字的人都能查看，请避免使用过于简单的名字，敏感内容务必设置访问密码
- 密码（空间密码与管理员密码）均以加盐 SHA-256 哈希存储，不存明文
- 会话使用 HMAC 签名的 Cookie（空间会话 30 天，管理员会话 2 小时）
- 解锁与管理员登录均有失败次数限速

## 技术说明

- 后端：Go 标准库（`net/http` 路由、JSON 文件存储、进程内定时任务），前端为原生 HTML/CSS/JS，通过 `go:embed` 内嵌进二进制
- 前端资源以 `?v=N` 版本参数引用：部署链路上的边缘代理会按文件扩展名缓存静态文件，仅替换文件可能不生效；修改前端后请同步递增 HTML 中的版本号
- 文件处理全程流式读写，不整文件载入内存
- 标签保存带修订号（rev）校验：多端冲突时返回 409 并刷新为最新内容
